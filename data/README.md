# CIOS — Cyto Intelligence Observation System

**Reality. Carefully Reconstructed.**

This repository is the public interactive research demo for CIOS, a Project Sixth Sense research system focused on 3D+t cell tracking, lineage reconstruction, temporal reasoning, and evidence governance.

## What this public demo contains

- interactive mission overview
- built-in illustrative 3D+t cell-motion demo
- optional microscopy / coordinate upload viewer
- AVG3 motion mathematics and measured pseudo-gap diagnostics
- ATR HOLD case study
- independent A-vs-D comparison
- Kaggle baseline-vs-final result
- next-phase research priorities

## Scientific honesty boundary

The built-in microscopy-like visualization is **synthetic and illustrative**. It exists so the public app is interactive without shipping research datasets.

It is not used for any reported result.

All numerical research metrics shown in the app come from the CIOS evidence ledger summarized in `SOURCE_LEDGER.md`.

This app does not run the CIOS detector, train a model, execute the competition ILP, mutate a scientific graph, create latent observations, or submit anything to Kaggle.
